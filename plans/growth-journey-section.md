# “成长经历”上半区改造计划

## 1. 目标

将 `public/replica/index.html` 中品牌栏目第三个画面 `.flyq_area3` 的上半区，由当前“超级工作场所”标题与副标题，改造成个人成长经历展示。

最终上半区包含：

- 主标题：`成长经历`
- 不显示副标题
- 不显示“阶段 / 经历 / 能力积累”表头
- 三个阶段以 01 / 02 / 03 展示：
  1. 工业设计与人机交互
     - 用户研究
     - 体验分析
     - 系统思维
  2. 支付业务产品实践
     - 业务分析
     - 流程设计
     - 项目落地
  3. AI 产品探索
     - Agent 设计
     - 模型评估
     - 产品验证

下半区现有左侧 Logo、右侧图片、分割线和相关动画保持原样。

## 3. HTML 调整

### 3.1 移动端辅助标题

将：

```html
<div class="top_tit __m">现代工程打造的办公未来</div>
```

改为：

```html
<div class="top_tit __m">成长经历</div>
```

如果新的主标题在移动端已经完整显示，可通过 CSS 隐藏该辅助标题，避免重复；优先保留现有节点以减少结构变化。

### 3.2 上半区内容

保留 `.top > .txt` 层级，替换其内部结构：

```html
<div class="txt growth-story">
  <strong class="growth-title"><span>成长经历</span></strong>
  <ol class="growth-journey">
    <li>
      <span class="growth-number">01</span>
      <h3>工业设计与人机交互</h3>
      <p>用户研究、体验分析、系统思维</p>
    </li>
    <li>
      <span class="growth-number">02</span>
      <h3>支付业务产品实践</h3>
      <p>业务分析、流程设计、项目落地</p>
    </li>
    <li>
      <span class="growth-number">03</span>
      <h3>AI 产品探索</h3>
      <p>Agent 设计、模型评估、产品验证</p>
    </li>
  </ol>
</div>
```

使用有序列表是为了让三个阶段在无样式和辅助技术环境中仍有清晰顺序。

### 3.3 编辑注释

更新该段旁边的中文注释，明确：

- 标题在 `.growth-title` 中替换。
- 每个阶段位于 `.growth-journey > li`。
- `growth-number` 是阶段编号。
- `h3` 是经历名称。
- `p` 是能力积累。
- 下半区 Logo 和图片不属于成长经历数据。

## 4. 桌面端布局

保持 `.flyq_area3 .top` 高度为当前的 50%，避免影响下半区。

在上半区内部：

- `.growth-story` 占据约 88%–92% 可用宽度。
- 主标题位于顶部或左上方，使用比原“超级工作场所”更紧凑的字号。
- `.growth-journey` 使用三列等宽网格。
- 三列之间使用细黑色竖线，呼应页面既有几何分割语言。
- 每列包含：
  - 小号阶段编号
  - 中号加粗经历名称
  - 较小的能力说明
- 不增加卡片圆角、阴影或渐变，保持原站硬边框、黑白网格视觉。

建议桌面尺寸：

- 主标题：约 `3.2vw`–`4vw`
- 阶段编号：约 `0.8vw`–`1vw`
- 经历名称：约 `1.25vw`–`1.55vw`
- 能力说明：约 `0.72vw`–`0.9vw`

具体值以 1440×900 截图中不换行、不拥挤为准。

## 5. 移动端布局

在现有 `max-aspect-ratio: 12/10` 媒体查询中增加成长经历专用规则：

- 上半区仍使用现有移动端高度分配。
- 主标题居中或左对齐显示一次，避免与 `.top_tit` 重复。
- 三阶段由桌面三列改为三行。
- 每行采用紧凑网格：
  - 左侧编号
  - 中间经历名称
  - 下方或右侧能力说明
- 行与行之间使用细横线。
- 保证最小 390×844 视口下三行内容全部可见。
- 保留下半区 Logo 与图片节点；如原图片与三行内容发生重叠，只调整移动端定位或层级，不删除素材、不改变桌面布局。

## 6. 动画

延续该页面现有的“先标题、后内容、再下半区素材”节奏。

初始状态：

- 主标题：`opacity: 0; transform: translateY(60%);`
- 三个阶段：`opacity: 0; transform: translateY(20%);`
- 阶段内部不再额外拆分动画，避免动画过碎。

激活状态使用现有前缀：

```css
.sd_start .ani .swiper-slide-active .flyq_area3 ...
```

建议时序：

- 主标题：`1.2s` 或沿用原标题 `1.5s`
- 阶段 01：`1.7s`
- 阶段 02：`1.9s`
- 阶段 03：`2.1s`
- 下半区左侧 Logo：继续沿用原 `2.5s`
- 下半区右侧图片：继续沿用原 `3s`

动画时长继续使用 `0.6s`，不改变 Swiper 切屏速度。

## 7. 不修改的内容

- 不修改 `.flyq_area3` 外部的 `.line type12` 至 `.line type21`。
- 不修改 Swiper 结构和第三画面的索引。
- 不修改 `.bot.lef` 与 `.bot.rig` 中的 Logo、标签和图片文件。
- 不修改其他五个栏目。
- 不修改 `global.js`。
- 不修改加载动画。

## 8. 边界情况

- `AI` 和 `Agent` 保留为行业术语，不翻译。
- 如果“工业设计与人机交互”在窄屏中换行，允许经历名称换成两行，但阶段编号和能力说明不得被遮挡。
- 能力内容保持中文顿号分隔，不拆成独立按钮，以减少空间占用。
- 不使用固定像素高度承载文字，避免字体加载后裁切。
- 保留现有中文字体声明，新增文字无需新增字体资源。

- 768×1024：响应式切换为纵向内容。
- 390×844：三个阶段全部可读，与下半区图片不重叠。

  1. 标题先出现。

- 从其他栏目切回品牌并再次进入第三画面时，动画能够重新播放。
